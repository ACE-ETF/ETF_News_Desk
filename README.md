# ETF 뉴스 데스크

국내 ETF 뉴스를 수집하고 주요 이슈·간단 요약·원문 링크로 확인하는 모바일 대응 뉴스 데스크입니다.

현재 운영 사이트: https://etf-news-desk-insik.openfawn16384.chatgpt.site/

## 현재 연결 상태

- 이 저장소는 2026-10-29 운영 버전의 소스 스냅샷입니다.
- 운영 호스팅과 한국 영업일 오전 8시 수집은 기존 Sites 환경에서 계속 실행됩니다.
- `main` 변경 시 GitHub Actions가 Pages 화면을 빌드하고 배포합니다. 최초 1회 저장소 Settings → Pages → Source를 GitHub Actions로 설정해야 합니다.
- 수집 기사, 요약 데이터, 운영 인증키, 호스팅 식별자와 로컬 실행 기록은 포함하지 않습니다.
- GitHub Pages는 뉴스 화면을 제공하고, 기존 Sites API와 R2가 수집·저장을 담당합니다. API 데이터는 페이지를 열거나 새로고침할 때 읽으므로 매일 재배포할 필요가 없습니다.

## 주요 기능

- 중요도·다양성을 고려한 핵심 이슈 최대 10건, 관련 기사 묶기
- 상품·수급·제도·운용 위험·배당 및 분배 이슈 분류
- 키워드 탐색, 기사 번호, 요약, 새 탭 원문 열기, 날짜별 보관 기사 조회
- 영업일 오전 8시 기준 직전 영업일 오전 8시부터 수집
- 주말·공휴일·연휴 기사 다음 영업일 합산
- 직접 확인한 이미지에만 노출 허용 (`lib/verified-images.ts`)
- 공유용 기본 이미지와 Open Graph 메타데이터

## 개발 환경

Node.js 22.13 이상과 `package.json`의 `packageManager`에 지정된 pnpm을 사용합니다.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

```bash
pnpm exec tsc --noEmit
node tests/collector.mjs
node tests/brief.mjs
pnpm build
```

로컬 화면에는 운영 데이터가 자동 복사되지 않습니다. 로컬 R2에 뉴스 데이터가 없다면 빈 목록이 표시됩니다.

## 구성

| 경로 | 역할 |
| --- | --- |
| `app/page.tsx`, `app/globals.css` | 뉴스 목록과 모바일 UI |
| `lib/news.ts` | RSS 수집, 기간 계산, R2 읽기·저장 |
| `lib/ranking.ts`, `lib/brief.ts` | 중요도와 이슈 묶기 |
| `lib/classify.ts`, `lib/holidays.ts` | 분류와 한국 영업일 |
| `lib/verified-images.ts` | 기사 ID·제목에 대응하는 검증 이미지 목록 |
| `app/api/collect/route.ts` | 인증된 수집 실행 |
| `app/api/summaries/route.ts` | 인증된 요약 저장 |
| `public/social/` | 공유 기본 이미지 |

## 운영 설정

- `BUCKET`: R2 저장소 바인딩
- `COLLECTOR_KEY`: 수집·요약 쓰기 API 인증키. 호스팅의 비밀 설정으로만 주입합니다.
- 수집 요청은 `POST /api/collect`와 `X-Collector-Key` 헤더를 사용합니다.
- 외부 스케줄러에서 한국 영업일 오전 8시에 호출하는 구조입니다. 이 저장소 자체에는 예약 실행 설정이 없습니다.
- Sites 이외의 호스팅으로 이전할 경우 Workers/R2 바인딩, 비밀 설정, 예약 실행, 기존 데이터 이전과 공유 이미지 URL 설정이 별도로 필요합니다.

## 이미지 검증

대표 이미지 메타데이터만으로 상품 일치를 판단하지 않습니다. 기사 제목·본문의 상품, 사진 속 상품명·설명·금액을 확인한 뒤 해당 기사 ID와 제목에만 이미지를 연결합니다. 확인되지 않은 이미지는 노출하지 않습니다.

## GitHub Pages 자동 배포

- 화면 주소(첫 배포 완료 후): https://ace-etf.github.io/ETF_News_Desk/
- 첫 설정: 저장소 Settings → Pages → Build and deployment → Source → GitHub Actions
- 배포 파일: `.github/workflows/pages.yml`
- 프런트엔드 전용 빌드: `npm install --prefix pages` 후 `npm run build --prefix pages`
- `pages/main.tsx`가 운영 앱의 `app/page.tsx`와 CSS를 그대로 사용합니다.
- Pages 화면은 공개 읽기 API만 사용합니다. 인증키는 프런트엔드와 Actions에 저장하지 않습니다.
- 서버 수집/분류/저장 코드 변경은 기존 Sites 서버 배포가 별도로 필요합니다. Pages 자동 배포 대상은 화면입니다.
- 저장소 Settings에서 Pages를 활성화하기 전에는 Actions의 Configure Pages 단계가 실패할 수 있습니다. 설정 후 Actions에서 재실행하세요.

## 국내·해외 구분

상장 시장 기준으로 국내·해외·공통/미분류를 선택합니다. 국내 상장 해외투자 ETF는 국내에 포함합니다. 제목과 검증된 요약에서 상품/시장 단서를 사용하며, 상장 시장을 확인할 수 없는 기사는 국내 또는 해외로 임의 배정하지 않습니다. 기본 화면은 국내입니다. 해외 화면은 한국어 기사와 별도 영어 뉴스 검색 피드(미국 상장 ETF·운용사·신상품·수급·제도)를 함께 추적합니다. 전 세계 모든 매체를 빠짐없이 수집하는 범위는 아닙니다. 한국 영업일 오전 8시 수집 주기는 두 시장에 동일하게 적용됩니다.

해외 영어 기사의 원제목은 유지합니다. 한국어 문구는 실제 본문을 확인한 '한국어 요약'과 원제목만 옮긴 '제목 번역'을 구분해 저장합니다(`summaryKind`). 자동 번역의 오역·누락 가능성을 화면에서 안내합니다. 번역되지 않은 전체 목록 기사는 영문 원문으로 표시하며, 실제 대기열이 없는 번역 대기 문구는 사용하지 않습니다. 매일 해외 확장 목록과 관련 기사에 나오는 미번역 영어 제목을 모두 번역합니다. 시세·반복형 글은 번역 대상에서 제외합니다. 새 제목만 묶어서 번역하고 기존 번역은 재사용합니다.

## 중복 보도 압축

같은 상품·사건·기간의 보도를 대표 기사로 묶습니다. 영문 수급 기사는 대상 자산/운용사/티커, 유입·유출 방향, 금액, 일간·월간 등 기간을 비교합니다. 명시된 기준일과 상품이 다르면 합치지 않습니다. 관련 기사는 접힌 상세에서 3건을 먼저 보여주고 더 보기를 제공합니다. 시세·옵션체인·반복형 투자글은 기본 제외하며 필터의 '시세·반복형 글 포함'으로 복원할 수 있습니다. 저장된 원본 기사는 삭제하지 않습니다. GPT 호출 없이 규칙으로 처리합니다.

기본 핵심 이슈는 국내·해외 각각 최대 10개로 압축합니다.

'ACE ETF' 키워드는 기사 유무와 관계없이 맨 앞에 항상 표시합니다. 선택하면 전체 상장 시장에서 ACE 브랜드/한국투자신탁운용의 ETF 관련 기사만 조회합니다. 관련 기사가 없는 경우 빈 상태 안내를 표시합니다.

공유 이미지는 `public/social/etf-news-card-ace-v2.png`입니다. ACE ETF 공식 로고 출처: https://www.aceetf.co.kr/static/images/logo_ace_blue_fit.svg (확인일 2026-10-29). 공식 벡터 원본은 `public/brand/ace-etf.svg`에 보관합니다.

공유용 화면에서는 개인 북마크 메뉴와 기사 저장 버튼을 제거했습니다. 날짜별 조회는 유지합니다. `GET /api/news?translations=1`은 현재 수집 구간의 미번역 해외 영어 기사만 반환합니다. 제목 번역은 10개씩 저장하되 전체 대상을 완료합니다.

날짜별로 원본을 누적 보관하되 기본 화면은 최근 영업일의 08시~08시 브리핑만 표시합니다. 날짜를 고르면 해당일 00시~24시(한국 시간) 발행 기사만 표시합니다. 과거 날짜에도 최신 중복 묶기 규칙을 적용하며 원본은 유지합니다.

KODEX 미국 대표지수 분배금 보도는 두 상품을 함께 다룬 발표가 확인된 경우 같은 날·분배월의 일반 제목과 단일 상품 보도를 그 발표에 연결합니다. 확인된 지급액·지급일과 다른 경우에는 합치지 않습니다.

국내 기관명·운용사 약칭·증권사 ETF 서비스·국내 제도 표현으로 시장 판별을 보완합니다. 명시된 해외 상품/상장 단서가 있으면 국내 증권사가 언급되어도 해외로 분류합니다. 제목만으로 확인되지 않는 국내 테마 추정은 하지 않습니다.

해외 수집은 주식·섹터, 채권, 금·원자재, 상품 출시·보수·제도를 별도 검색하고 가상자산을 제외합니다. 가상자산 뉴스는 전용 검색 1개로 유지합니다(영문 검색 총 5개). 핵심 브리핑의 가상자산 이슈는 최대 1개로 제한하며, 전체 뉴스에서는 원본을 계속 볼 수 있습니다. 이 처리는 GPT 호출 없이 실행됩니다.

### 요청량 제한
해외 영문 검색을 5개에서 3개(주식·상품/제도, 채권·원자재, 가상자산)로 줄였습니다. 국내 3개를 포함해 매 영업일 최대 6개 검색을 1개씩, 2초 간격으로 요청합니다. 주말·연휴도 전체 기간을 한 검색 구간으로 지정해 날짜 수만큼 요청을 늘리지 않습니다. 429/503은 추가 RSS 요청을 즉시 중단하고 당일 재시도하지 않습니다. R2의 수집 구간별 원자적 기록으로 중복 실행도 차단합니다. 기사량을 줄여 요청을 제한하는 운영 기준이며 외부 제공자의 차단 방지를 보장하지는 않습니다.

### 공통 인사이트
국내·해외·전체 3개 탭을 사용합니다. 상장 시장이 불확실하거나 공통인 기사 중 투자 아이디어·오피니언·업종/지수 변화·글로벌 운용업계 분석 단서가 있는 경우에만 두 시장 화면에 '공통 인사이트'로 함께 표시합니다. 기타 미확인 기사는 전체 목록에 보존합니다. 첫 화면과 전체 목록은 10개부터 표시합니다. 핵심 이슈는 20점 이상에서 최대 10개를 고르며 분석 기사 전용 자리는 없습니다. 지수·편입 변화는 15점, 아이디어·오피니언·산업/운용업계 분석은 8점의 보조 신호만 적용합니다. 이미 신상품·위험·수급 등 다른 점수 신호가 있으면 분석 점수를 중복 가산하지 않습니다. 같은 규칙을 앞으로 수집되는 기사에도 적용합니다. 원문 발행일이 피드 시각과 다르다고 확인된 과거 기사는 날짜를 함께 표시하고 핵심에서는 제외합니다. 분류·선정 규칙은 GPT 추가 호출 없이 작동합니다.

전체 화면은 국내 상장 → 공통 인사이트 → 해외 상장 → 기타 미확인 순으로 표시합니다. 각 시장 안에서 선택한 중요도순 또는 최신순을 적용합니다. 국내 상장 미국투자 상품도 국내 순서에 포함합니다.
